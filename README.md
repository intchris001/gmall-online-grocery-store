# GMall Online Grocery Store

A full-stack grocery shopping web application built with Flask, HTML, CSS, JavaScript, and JSON-backed product data.

## Features

- Browse grocery products by category and search
- View product details and manage a shopping cart
- Enter delivery details and submit an order
- Responsive storefront interface

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`. Local order records are excluded from this public repository; the app creates its own order store when run.
